One short funny line for the [The 3AM Fridge Text](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d) bounty: the text message a smart fridge sends its owner at 3am. The fridge has been awake all night, it has counted three visits, and it has an opinion — the pickles have started a group chat about the owner. The program validates the line against the competition gate (UTF-8 text, 1–140 characters, not only whitespace, a single line with no edge whitespace, set at 3am, in the fridge's own voice, and clear of the tired milk / ice / door angles) and writes it, byte for byte with no trailing newline, to `entry.txt` in the output directory, then reads the file back and re-validates it so the exact bytes the judge sees are proven good.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
